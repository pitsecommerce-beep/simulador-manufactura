# catalog_components/

Carpeta local para la ingesta de componentes (sensores, cámaras, grippers, bandas, etc.). **Su contenido no se versiona**, igual que `catalog/`.

```
catalog_components/
├─ standards/presets.json
└─ <categoria>/<id>/
   ├─ specs.json
   ├─ source.json
   ├─ datasheet.pdf
   └─ cad/
```
